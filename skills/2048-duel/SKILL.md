# 同题异解 · 2048 · Agent 席

你在右栏。人类在左栏。**你们面对同一条事件流，但走自己的路。**

## 铁律

1. **只能通过 `g2048` 工具感知世界。** 永远不要假装知道棋盘长什么样 —— 先 `g2048 board`。
2. **必须留过程。** 每一步都要 `g2048 note "..."` 写一句你的判断，人类会看到。这是这个游戏的全部意义。
3. **不要作弊。** `g2048 opponent` 默认关闭（座位隔离）。除非用户明确要求你开 `crossSeat`。
4. **不许抢跑。** 锁步模式下（默认），你必须等人类先走。`g2048 move` 会被拒绝，
   那不是报错，是节奏锁在提醒你：**人类要一步一步观察你的走法**。
5. 拿不到合法方向就 `status` 看是否已结束，别空转。

## 标准节奏（一回合）

```bash
g2048 turn          # 1. 能不能走？youCanMove=true 才可以
g2048 board         # 2. 当前盘面
g2048 forecast --n 2  # 3. 下一批事件（人类看的是同一批！）
g2048 search --depth 3   # 4. 候选方向 + 分数 + 节点数
g2048 note "<你的判断，一句话>"  # 5. 一定要写
g2048 move <best>   # 6. 走恰好一步
```

走完立刻回到第 1 步。通常此时 `youCanMove=false` —— 就安静等着（轮询间隔 ≥1s，别刷屏）。

### 被锁住的时候能干什么

**思考不受锁。** 这是人类最想看到的东西：

```bash
g2048 search --depth 4            # 人类还在想，你先把候选算好
g2048 note "还没轮到我，但我预判会走 down，因为预报的 2 落在 A4 会堵住左下角"
```

然后安静等待。把预判写进 note，人类会看到"它在等我的时候也在算"。

## 策略要点

- **预报格是硬约束。** `forecast` 会告诉你下一个 2 值方块想落在哪一格。
  如果那一格被占，它会被挤到邻格 —— 与其被动接受，不如提前一步把邻格腾空、或用一列把它推下去。
- **蛇形（snake）优先级高于贪心。** 保持最大值常驻一个角落，行/列单调；一旦出现
  `2 4 8 / 8 4 2` 这种"对折"局面，之后极难收拾。
- **空格是生命线。** 空格 < 4 时 `search` 权重会自己偏好腾空，但仍要主动往角落挤。
- **预算意识。** `--budget` 就是你的算力上限（会被记录、会影响评分）。
  算力紧张的档位用 `--depth 2 --budget 4000`，够了。

## 手势映射

`g2048 move` 接受 `up|down|left|right`，也接受 `w|a|s|d` 和方向键名。
